Packages

Two npm libraries power Unicode and pronunciation. Install them in your own project, or try them live.

Open playground

Each ships .mjs, .cjs, and TypeScript types.

Antonios-font Latin keyboard text → standard Coptic Unicode (amyn → ⲁⲙⲏⲛ). 

npm install coptic-antonios-unicode
import { toUnicode } from 'coptic-antonios-unicode';

const unicode = toUnicode('amyn');
console.log(unicode);
npm · coptic-antonios-unicode →

Coptic Unicode → English and Arabic phonetics via pronounce. Reverse guess with guessCoptic / toCoptic. 

npm install coptic-pronounce
import { pronounce } from 'coptic-pronounce';

console.log(pronounce('ⲁⲙⲏⲛ', 'en'));
console.log(pronounce('ⲁⲙⲏⲛ', 'ar'));
